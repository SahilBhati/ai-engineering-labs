# AI Engineering Labs

Understand the model you're serving: interactive lessons on how LLMs work, for software engineers.

## Lessons

1. [Tokens, embeddings, attention](lessons/llm-foundations-1/index.md): 19 interactive steps
2. [The block, sampling, the KV cache](lessons/llm-foundations-2/index.md): 13 interactive steps
3. Training and inference economics (coming next)

## Tools

- [AGF](https://github.com/SahilBhati/ai-engineering-labs/tree/main/tools/agf): A skill factory for a markdown vault: agents propose changes as git commits, you approve them, and repeated corrections become rules.
- [usage-tracker](https://github.com/SahilBhati/ai-engineering-labs/tree/main/tools/usage-tracker): Reads Claude Code's local logs: the current 5-hour window, the last 7 days, per project and model. No API key, no dependencies.
