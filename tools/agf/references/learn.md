# learn — managed by AGF

Log misses and draft rule candidates. Part of the AGF skill factory:
this skill is managed by AGF, it is not the tool itself.

Factory rules that apply: propose, don't write. Accepted rules enter
the structure note or the agent protocol as a proposed batch, never as
a silent edit.

1. When a rule is missed or a task needs rework, log the miss to
   800-Agent-Records: what happened, which rule or note was involved,
   and what would have prevented it. When the user corrects how the
   agent works with them — tone, pacing, format, a wrong assumption
   about them — log that as a miss too, tagged `profile`.
2. When the same miss repeats 3 times, draft a rule candidate: the
   rule text, the evidence (the 3 misses), and where it belongs.
   Misses tagged `profile` belong in the profile's Accepted rules.
3. Present the candidate for the user to accept or reject. Accepted
   rules go into the profile, the structure note, or the agent
   protocol as a proposed batch. Rejected candidates are logged with
   the reason.

Done when: the miss is logged, and any third repeat has produced a
rule candidate awaiting a decision.
