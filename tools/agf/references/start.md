# start — managed by AGF

Load context, bind the session, and write a brief. Part of the AGF
skill factory: this skill is managed by AGF, it is not the tool itself.

Factory rules that apply: propose, don't write — this routine writes
only to 800-Agent-Records, never to core notes. Every open question
carries a recommended answer and a working assumption.

1. Load L0 (`000-Meta/Profile.md`) first, then L1 (the structure note
   and the agent protocol). If the profile is missing or still the
   empty template, say so in the brief and recommend filling it
   before other work.
2. Read the rolling recent-context note in 000-Meta and the inbox
   queue in 100-Inbox.
3. Write a short session brief to 800-Agent-Records: goal, next
   action, open questions with a recommended answer and a working
   assumption for each.

Done when: the brief exists in 800-Agent-Records and the session can
proceed without re-reading the whole vault.
