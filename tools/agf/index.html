Open source · Agent skill · MIT

Agents propose. You approve. Your notes learn.

AGF turns a markdown notes vault into a knowledge base AI agents can help maintain, without ever changing it behind your back.

  • Agents write only to an inbox. Your real notes stay untouched.
  • Every change arrives as one git commit that waits for your yes.
  • Repeated corrections become rules you accept or reject.

What's inside
One folder. One skill file. Four routines.

    
Agents load only the short skill file up front, then open a routine when its job comes up. Your vault stays plain markdown: remove AGF and every note is still there.

  
agf/
├── SKILL.md        factory model + router
├── references/
│   ├── start.md    session brief
│   ├── triage.md   inbox → proposed batch
│   ├── check.md    no-model vault lint
│   └── learn.md    misses → rule candidates
└── vault-template/ empty vault to start from






  
Install
Copy one folder

    
Needs git and a markdown vault (Obsidian optional). Works with Claude Code and other Agent Skills-compatible agents.

    View on GitHub ↗

  

    
Claude Code, personal
cp -r tools/agf ~/.claude/skills/agf/

    
Project (Codex, Cursor, OpenCode, …)
cp -r tools/agf .agents/skills/agf/

    
Then ask your agent
Set up my vault with AGF

  

  
Run the copy commands from a clone of the repository. AGF asks for your vault path before doing anything else.
