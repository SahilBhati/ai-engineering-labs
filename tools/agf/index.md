# AGF: agents propose, you approve, your notes learn

AGF turns a markdown vault into a knowledge base AI agents can help maintain without changing it behind your back.

- Agents write only to an inbox.
- Every change arrives as one git commit that waits for your yes.
- Repeated corrections become rules you accept or reject.

Install: `cp -r tools/agf ~/.claude/skills/agf/` (Claude Code) or `cp -r tools/agf .agents/skills/agf/` (other Agent Skills agents), then ask: "Set up my vault with AGF".
