01AGF

AI agents work on your notes, but you can't see what they changed or why, and every session starts from zero.

A skill factory for a markdown vault: agents propose changes as git commits, you approve them, and repeated corrections become rules.

02usage-tracker

Claude subscription limits aren't exposed by any API, so it's hard to plan work around them.

Reads Claude Code's local logs: the current 5-hour window, the last 7 days, per project and model. No API key, no dependencies.
