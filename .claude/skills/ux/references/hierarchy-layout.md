# Hierarchy and layout

## Hierarchy: three levers

Importance is expressed with **size, weight and color**, in that order of
strength. Not everything can be important:

- One primary element per view (the headline) and **one primary action** (a
  filled button). Everything else is secondary (outlined) or tertiary (a link).
- Emphasize by **de-emphasizing the competition**: mute secondary text with a
  lighter color, not a lighter font weight.
- Body text 400–500 weight; emphasis 600–700. Don't use more than three sizes
  in one component.

## Spacing and grouping

- Use a constrained scale: 4, 8, 12, 16, 24, 32, 48, 64, 96 px. Never arbitrary values.
- **Proximity**: related things sit close together; groups are separated by
  clearly more space than items within a group (at least 2× the inner gap).
- Generous whitespace between sections (64–96 px on desktop). Cramped is the
  most common reason a page looks "average".
- Align everything to a few vertical lines. A ragged left edge reads as noise.

## Laws worth applying (lawsofux.com)

- **Jakob's law**: people expect your site to work like sites they already use.
  Logo top-left linking home; main nav in the header; for courses and docs a
  left side nav; the current location highlighted.
- **Hick's law**: decision time grows with the number of choices. Keep the
  header to 4–6 items and one call to action.
- **Fitts's law**: big, close targets are faster. Primary buttons ≥ 44 px tall;
  put the next action where the eye already is.
- **Aesthetic-usability effect**: attractive designs feel easier to use, which
  can hide real problems. Polish never replaces a working flow.

## Layout patterns for learning sites

- Header (brand, 4–6 nav items, one CTA) + sticky left nav (sections, current
  page marked) + a content column of 60–75 characters for prose.
- Course overview as a numbered list or grid with progress or status per item.
- Lesson pages: where am I (breadcrumb or nav), what's next (prev/next always
  visible), and how far along (progress).
- Cards only when items are truly separate objects. Prefer shared-border grids
  or plain lists; the same rounded card everywhere looks generic.

## Tests

- **Squint test**: blurred, do the headline and primary action still lead?
- **Grayscale test**: without color, is the hierarchy still clear?
- **5-second test**: can someone say what the page is and what to do next?
